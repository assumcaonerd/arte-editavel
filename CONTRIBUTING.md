# Como contribuir

Obrigado pelo interesse em melhorar o Arte Editável. Contribuições são bem-vindas para corrigir erros, melhorar a documentação, aperfeiçoar a interface ou desenvolver novas funções.

## Antes de começar

1. Consulte as issues existentes para evitar trabalho duplicado.
2. Para mudanças maiores, abra primeiro uma issue explicando a proposta.
3. Nunca inclua senhas, tokens, chaves de API, dados pessoais ou imagens privadas.
4. Mantenha cada pull request concentrado em uma única correção ou melhoria.

## Fluxo recomendado

1. Faça um fork do repositório.
2. Crie uma branch descritiva, como correcao/exportacao-png.
3. Instale as dependências e execute npm install e npm run check.
4. Faça commits claros e objetivos.
5. Envie um pull request usando o modelo fornecido.

## Critérios para aprovação

Uma contribuição deve explicar o problema ou benefício, preservar as funções existentes, passar nas verificações automáticas e não comprometer a segurança ou a privacidade. A decisão final de incorporar cada contribuição cabe ao mantenedor do projeto.

## Relatos e sugestões

Use os modelos de issue para relatar erros ou sugerir funções. Inclua passos para reprodução, navegador, sistema operacional e imagens quando forem úteis, removendo previamente qualquer informação sensível.
